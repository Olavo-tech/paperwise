# Sandbox Paperwise

Only test keys are accepted. The isolated tables paperwise_stripe_test and paperwise_stripe_test_events never grant production entitlements. Configure privately in Vercel: STRIPE_TEST_ENABLED, STRIPE_TEST_KEY (restricted test key), STRIPE_TEST_PRICE_ID (recurring test price), STRIPE_TEST_WEBHOOK_SECRET, STRIPE_TEST_USERS (comma-separated verified tester emails). Never put keys in Git. Use webhook /api/stripe/test-webhook with checkout.session.completed, checkout.session.async_payment_succeeded, customer.subscription.created/updated/deleted/paused/resumed, invoice.paid and invoice.payment_failed. Configure test Customer Portal. Verify signed webhook, duplicate delivery, cancellation, failed payment and renewal; this is not live billing. Before commercial activation, an authorized adult must review contracts, price, tax, fraud/refund/dispute handling, separate production database/entitlements and production credentials. No real card data in tests.
